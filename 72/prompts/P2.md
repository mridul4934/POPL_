# P2 prompts (word for word)

Tool: Claude Code, with the `prolog-dev` skill (`72/skills/prolog-dev/SKILL.md`).
One prompt per unit of work.

## 1. Expression generator

> Using the prolog-dev skill, write expr(Nums, Tree, Value) in 72/code/72_q2.pl for P2. It should generate, on backtracking, every expression tree over the non-empty list Nums (numbers used in order, each once, operators + - * /) together with its integer value. Division is allowed only when the divisor is non-zero and the division is exact, at every level.

## 2. Canonical printer

> Using the prolog-dev skill, write a predicate that turns an expression tree from expr/3 into its canonical string for P2: no spaces, * and / bind tighter than + and -, left operands get parentheses only if their operator has lower precedence than the parent's, right operands if it has the same or lower precedence, and single numbers never get parentheses.

## 3. generate_equation/2 (P2.a)

> Using the prolog-dev skill, write generate_equation(List, Equation) for P2.a using expr/3 and the printer. It splits List into two non-empty parts, finds expressions with equal values on both sides, and returns "L=R" as an SWI-Prolog string. It must fail, not loop or raise an error, when no equation exists, including for lists of length 0 or 1.

## 4. all_equations/2 and count_equations/2 (P2.b)

> Using the prolog-dev skill, write all_equations(List, Equations) and count_equations(List, N) for P2.b. Equations is every valid equation string with no duplicates, sorted with sort/2, or [] if there are none. Check it against the examples [4,2,5,3], [2,3,4] and [2,4,8] from the assignment.

## 5. Tests

> Using the prolog-dev skill, write 72/tests/test_q2.pl with plunit tests for P2: all examples from the assignment, the parenthesis examples, and edge cases (empty list, one number, zeros, division by zero, non-exact division, negative intermediate values). Run it and make sure it passes.

## 6. Final review

> Using the prolog-dev skill, review 72/code/72_q2.pl against the P2 constraints: allowed libraries only, no assert/retract/global variables, no printing, no building a string and parsing it back, and reasonable speed on a list of 6 to 7 numbers.
