# P1 prompts (word for word)

Tool: Claude Code, with the `prolog-dev` skill (`72/skills/prolog-dev/SKILL.md`).
One prompt per unit of work. Prompts 1 and 2 set up the repository and the skill file
before P1 itself.

## 1. Repo layout and plan

> For our CS F301 Assignment 2 (group 72), create the repo layout from section 4 of the assignment: 72/code, 72/tests, 72/skills, 72/prompts, plus a README.md and a PLAN.md that assigns P1 to Mridul, P2 to Pratyush, S1 and the scheme-dev skill to Raghav, and S2 to Vedant, with the rules each of us must follow.

## 2. prolog-dev skill

> Write the prolog-dev skill file at 72/skills/prolog-dev/SKILL.md: YAML header with name and description, SWI-Prolog 9.x, allowed libraries and forbidden constructs from the assignment, coding conventions with a declarative reading for each predicate, how to run and test, a self-review checklist, and known AI failure modes in Prolog.

## 3. Domains and generator

> Using the prolog-dev skill, write the attribute domains and a solution/1 generator in 72/code/72_q1.pl for P1. It should produce every assignment of departments, languages and projects to Alex, Ben, Carla, Dana in that order, as p(Name, Dept, Lang, Project) terms, with each value used exactly once and atoms exactly as the spec gives them.

## 4. Clues 1-8

> Using the prolog-dev skill, write clue(N, Solution) for clues 1 to 8 of P1, each as its own clause with the English clue in a comment above it, succeeding exactly when that clue holds in a fully filled-in solution.

## 5. main/0 (P1.a)

> Using the prolog-dev skill, write main/0 for P1.a. It derives one solution of clues 1-8 from solution/1 and clue/2 (not hard-coded) and prints four lines in the format "Alex = [dept, lang, project]", in the order Alex, Ben, Carla, Dana, with nothing else printed.

## 6. count_solutions/2 (P1.b)

> Using the prolog-dev skill, write count_solutions(Active, N) for P1.b, which counts the solutions satisfying exactly the clues listed in Active using aggregate_all/3 or findall/3. Tell me N for [1,2,3,4,5,6,7,8].

## 7. Report (P1.b)

> Write 72/P1_REPORT.md with the value of N for clues 1 to 8, the solutions it finds, and what this tells us about the puzzle.

## 8. Clue 9 (P1.c)

> Using the prolog-dev skill, add clue(9, Solution) for P1.c so that count_solutions([1,2,3,4,5,6,7,8,9], N) gives N = 1. It must not name any friend, must be true in the one solution kept and false in every other solution of clues 1-8, and must have a "% CLUE 9:" comment directly above it. Add a short section on it to P1_REPORT.md.

## 9. Tests

> Using the prolog-dev skill, write 72/tests/test_q1.pl with plunit tests for P1: the generator, a near-miss case for every clue, count_solutions including edge cases, clue 9, and the exact output of main. Run it and make sure it passes.
