# S2 prompts (word for word)

Tool: Claude Code, with the `scheme-dev` skill (`72/skills/scheme-dev/SKILL.md`).
One prompt per unit of work.

## 1. my-length and my-map

> Using the scheme-dev skill, write my-length and my-map in 72/code/72_q4.rkt for S2.b, using only the allowed built-ins. my-length must be tail recursive so it works on lists of 10,000 elements.

## 2. insert-if-short (first version)

> Using the scheme-dev skill, write (insert-if-short x lst n) for S2.b using my-length and my-map. It inserts x at the front of every list, at every level of nesting including the top level, whose original length is less than n. Check it on the four examples from the assignment.

## 3. print-insert-result (S2.a)

> Using the scheme-dev skill, write print-insert-result for S2.a. It takes no arguments, reads x, lst and n with read in that order, and prints the result of insert-if-short with display followed by a newline, with no prompt or other text.

## 4. make-inserter (S2.c)

> Using the scheme-dev skill, write the higher-order function (make-inserter x len-ok?) for S2.c. It returns a one-argument function that inserts x at the front of every list, at every level of nesting, whose original length satisfies len-ok?. Then redefine insert-if-short using make-inserter so the file has only that one definition of insert-if-short.

## 5. Tests

> Using the scheme-dev skill, write 72/tests/test_q4.rkt that runs print-insert-result on the four standard-input examples from the assignment and checks the exact output, plus edge cases: n = 0, n = 1, empty sublists, symbols, nesting depth 100 and a list of 10,000 elements. Run it and make sure it passes.

## 6. Final review and repo check

> Using the scheme-dev skill, review 72/code/72_q4.rkt against the Scheme rules: only allowed built-ins plus read, nothing called or printed at top level, #lang racket/base first, a single definition of insert-if-short that uses make-inserter, and no problems on deep or long inputs. Then check the whole repo against the final checklist in PLAN.md.
