# S1 prompts (word for word)

Tool: Claude Code, with the `scheme-dev` skill (`72/skills/scheme-dev/SKILL.md`).
One prompt per unit of work.

## 1. Skill file

> Write the scheme-dev skill file at 72/skills/scheme-dev/SKILL.md: YAML header with name and description, Racket 8.x with #lang racket/base, the exact list of allowed built-ins from the assignment, coding conventions with a recursive reading for each function, how to run and test, a self-review checklist, and known AI failure modes in Scheme.

## 2. Tree helpers

> Using the scheme-dev skill, write the tree accessor helpers (node-value, node-left, node-right, empty-tree?, leaf?) in 72/code/72_q3.rkt for S1, using only the allowed built-ins.

## 3. Traversals

> Using the scheme-dev skill, write inorder, preorder and postorder for S1 in 72_q3.rkt. Each returns the list of values in that order, passing all state through arguments and using an accumulator so no append is needed.

## 4. Printing functions (S1.a, S1.b)

> Using the scheme-dev skill, write print-inorder and print-all-traversals for S1.a and S1.b. They print with display and end every line with a newline; check them on t1, t2, t3 and the empty tree from the assignment.

## 5. Height and leaves (S1.c)

> Using the scheme-dev skill, write height, leaf-count and print-height-and-leaves for S1.c, following the assignment's conventions (empty tree has height 0, a leaf has both subtrees empty), and check them on t1, t2, t3 and the empty tree.

## 6. Tests

> Using the scheme-dev skill, write 72/tests/test_q3.rkt that checks the exact printed output of all three S1 functions on every example in the assignment plus edge cases (single node, left-only and right-only chains, a deep tree). Run it and make sure it passes.

## 7. Final review

> Using the scheme-dev skill, review 72/code/72_q3.rkt against the Scheme rules: only allowed built-ins, nothing called or printed at top level, #lang racket/base first, and tail recursion where it is natural.
